# Install Strength in Character 1.1.0

This is the Android app a friend can install from the APK. It is not on the Play Store. Workout data stays on the phone. Installing this build over an earlier Strength in Character test build keeps that data, because it uses the same signing key and the same app id.

## Allow the install

1. Copy `strength-in-character-1.1.0.apk` onto the phone (USB, a shared drive, or a message you trust).
2. Open the file.
3. If Android says the install is blocked, allow installs from this app:
   - Android 8 and newer: tap Settings on the prompt, then allow **Install unknown apps** for the app that opened the file (Files, Chrome, or Drive). Go back and tap Install.
   - Older Android: Settings → Security → **Unknown sources**.
4. Tap Install, then Open. The name on the home screen is **Strength in Character**.

Uninstalling the app deletes workout data that was not exported. Before you uninstall, use Settings → Data & files → Export XML and keep that file.

## Mini over other apps

The in-app Mini button always works inside Strength in Character. Floating that same mini over other apps needs one system permission:

1. Open Strength in Character → Settings → Input & mini → Permission.
2. Android opens **Display over other apps** (some phones call it Appear on top).
3. Turn it on for Strength in Character, then come back and tap Show mini.

You can turn that permission off later in system settings. The mini is a small window. Drag it by the handle. It does not replace the full app.

## Updating

Install the new APK the same way and choose Update if Android offers it. Do not uninstall first if you want to keep the logs already on the phone.
