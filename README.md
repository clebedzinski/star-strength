# Star Strength

A spreadsheet-style workout logger built as a single HTML file, developed with Google Gemini as an AI coding partner.

**Live app:** https://clebedzinski.github.io/star-strength/

## Features
- Editable routines with shareable routine codes, including a default "Bigger Leaner Stronger 5-Day" program
- Per-exercise logging with previous-week reference data
- Rest and tempo timers, pinned header and routine bar
- Duo mode for training partners, with separate history and timers for each person
- Editable workout history with dates, and progress charts
- Embedded Spotify player
- Saves data in the browser (localStorage), no account needed

## Built with
HTML, CSS (Tailwind), JavaScript, Chart.js, Font Awesome. Next step: packaging as an Android app (WebView / Capacitor).
